# Пользовательская инструкция

## Что делает интеграция

В карточке сделки amoCRM есть виджет `Яндекс.Формы`.

Он позволяет:
- выбрать нужную форму;
- получить готовую ссылку для клиента;
- скопировать эту ссылку одной кнопкой.

Когда клиент заполнит форму, ссылка на его ответ в Яндекс.Формах автоматически сохранится в сделке amoCRM.

## Как создать новую форму в Яндекс.Формах

1. Откройте кабинет Яндекс.Форм:
   `https://forms.yandex.ru/cloud/admin/`
2. Нажмите `Создать форму`.
3. Укажите название формы.
4. Добавьте нужные вопросы для клиента.
5. Опубликуйте форму.

Важно:
- скрытые поля создавать не нужно;
- `amo_lead_id` и `amo_portal` вручную в форму добавлять не нужно.

## Как настроить интеграцию у формы

После создания формы нужно настроить webhook.

1. Откройте нужную форму.
2. Перейдите в раздел уведомлений, действий или интеграций формы.
3. Добавьте webhook.
4. Укажите адрес:

```text
https://srm.chinatutor.ru/yandex_forms_webhook.php
```

5. Сохраните настройки.

Важно:
- у формы должен быть только один рабочий webhook на этот адрес;
- ссылку webhook нужно прописывать отдельно в каждой новой форме.

## Как отправить форму клиенту из amoCRM

1. Откройте нужную сделку в amoCRM.
2. Справа в карточке найдите виджет `Яндекс.Формы`.
3. В выпадающем списке выберите нужную форму.
4. Ниже появится готовая ссылка.
5. Нажмите кнопку `Скопировать ссылку`.
6. Отправьте эту ссылку клиенту любым удобным способом.

Важно:
- клиенту нужно отправлять ссылку именно из виджета amoCRM;
- не копируйте публичную ссылку формы вручную из Яндекса, иначе сделка может не определиться.

## Откуда брать ссылку для клиента

Ссылку для клиента нужно брать только в amoCRM:

1. открыть сделку;
2. открыть виджет `Яндекс.Формы`;
3. выбрать форму;
4. нажать `Скопировать ссылку`.

Именно эта ссылка уже содержит служебные параметры, которые связывают ответ клиента с нужной сделкой.

Пример такой ссылки:

```text
https://forms.yandex.ru/u/6a738889381ea61914181597/?amo_lead_id=29450109&amo_portal=directorchinatutorru
```

## Что происходит после заполнения формы

1. Клиент заполняет форму.
2. Яндекс.Формы отправляют webhook на сервер.
3. Сервер определяет сделку amoCRM.
4. В сделку автоматически записывается ссылка на ответ клиента в Яндекс.Формах.

## Если форма не появляется в виджете

Проверьте:
- форма создана в том же кабинете Яндекс.Форм организации;
- у формы есть опубликованная публичная ссылка;
- виджет установлен в amoCRM;
- серверный адрес формы работает.

## Если ответ не записался в amoCRM

Проверьте:
- у формы настроен webhook:
  `https://srm.chinatutor.ru/yandex_forms_webhook.php`
- клиенту была отправлена ссылка именно из amoCRM;
- форма была заполнена после отправки правильной ссылки.
